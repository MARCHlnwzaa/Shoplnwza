# MyShop — เว็บไซต์ขายของ (PHP + MySQL + XAMPP)

เว็บไซต์อีคอมเมิร์ซตัวอย่าง ธีมสีแดง-ดำ-เทา ทันสมัย พร้อมระบบสมาชิก ตะกร้าสินค้า
สั่งซื้อ และแผงควบคุมแอดมิน แยกไฟล์โค้ดเป็นสัดส่วน เชื่อมต่อฐานข้อมูล MySQL ด้วย PDO

## โครงสร้างไฟล์

```

│   └── footer.php           # ส่วนท้าย
├── admin/                    # แผงควบคุมผู้ดูแลระบบ
│   ├── index.php             # แดชบอร์ด

│   ├── orders.php            # จัดการคำสั่งซื้อ
│   ├── users.php             # จัดการสมาชิก
```

## วิธีติดตั้งบน XAMPP

1. ติดตั้ง [XAMPP](https://www.apachefriends.org/) แล้วเปิดโปรแกรม เปิดใช้งาน **Apache** และ **MySQL**
2. คัดลอกโฟลเดอร์ `shop` ทั้งหมดไปไว้ที่ `C:\xampp\htdocs\shop` (Windows) หรือ `/Applications/XAMPP/htdocs/shop` (Mac)
3. เปิดเบราว์เซอร์ไปที่ `http://localhost/phpmyadmin`
4. สร้างฐานข้อมูลใหม่ หรือ Import ไฟล์ `database/shop.sql` โดยตรง (ระบบจะสร้างฐานข้อมูล `shop_db` ให้อัตโนมัติ)
5. ตรวจสอบไฟล์ `config/database.php` ว่า DB_USER / DB_PASS ตรงกับ MySQL ของคุณ (ค่าเริ่มต้น XAMPP คือ user `root` ไม่มีรหัสผ่าน)
6. เข้าเว็บไซต์ที่ `http://localhost/shop/`

### บัญชีทดสอบ
- **แอดมิน**: username `admin` / password `password` → เข้าที่ `http://localhost/shop/admin/`
- หรือสมัครสมาชิกใหม่ผ่านหน้า "สมัครสมาชิก" (จะได้สิทธิ์ลูกค้าโดยอัตโนมัติ)

## ฟีเจอร์หลัก

- ✅ สมัครสมาชิก / เข้าสู่ระบบ / ออกจากระบบ
- ✅ ระบบตะกร้าสินค้าแบบ AJAX (เพิ่ม/ลบ/แก้ไขจำนวน โดยไม่ต้องโหลดหน้าใหม่)
- ✅ ระบบสั่งซื้อพร้อม Transaction (กันสต็อกสินค้าไม่ตรงกันเมื่อสั่งซื้อพร้อมกันหลายคน)
- ✅ หน้าโปรไฟล์แบบแท็บ (สลับหน้าต่างข้อมูลส่วนตัว/ประวัติคำสั่งซื้อ/เปลี่ยนรหัสผ่าน)
- ✅ แผงควบคุมแอดมิน: แดชบอร์ด, จัดการสินค้า (CRUD + อัปโหลดรูป), จัดการคำสั่งซื้อ, จัดการสมาชิก
- ✅ ค้นหาและกรองสินค้าตามหมวดหมู่
- ✅ ธีมสีแดง-ดำ-เทา ทันสมัย รองรับมือถือ (Responsive)

## ระบบความปลอดภัยที่ใช้

| หัวข้อ | วิธีป้องกัน |
|---|---|
| SQL Injection | ใช้ PDO Prepared Statements ทุกคำสั่ง SQL |
| XSS | ใช้ฟังก์ชัน `clean()` (htmlspecialchars) ก่อนแสดงผลทุกครั้ง |
| CSRF | สร้าง CSRF token ทุกฟอร์ม และตรวจสอบก่อนประมวลผล |
| Session Hijacking | `session_regenerate_id()` ตอนล็อกอิน, cookie httponly |
| Brute Force | ล็อกบัญชีชั่วคราวหลังกรอกรหัสผิดครบ 5 ครั้ง |
| รหัสผ่าน | เข้ารหัสด้วย `password_hash()` (bcrypt) ไม่เก็บรหัสดิบ |
| การอัปโหลดไฟล์ | ตรวจสกุลไฟล์/ขนาด, สุ่มชื่อไฟล์ใหม่, บล็อกการรันสคริปต์ในโฟลเดอร์รูปภาพ (.htaccess) |
| การเข้าถึงไฟล์ config | บล็อกการเข้าถึงตรงผ่านเบราว์เซอร์ด้วย .htaccess |
| สิทธิ์การใช้งาน | ตรวจสอบ role (customer/admin) ทุกหน้าที่ต้องใช้สิทธิ์ |

## หมายเหตุ

- ต้องมี PHP 8.0+ พร้อม extension `pdo_mysql` เปิดใช้งาน (XAMPP เปิดให้อัตโนมัติ)
- หากต้องใช้งานจริงบน production ควรเปิด HTTPS และตั้งค่า cookie `secure => true` ในไฟล์ `includes/functions.php`
